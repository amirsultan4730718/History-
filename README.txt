ClipPulse AI Studio — static deployment package

Contents:
- index.html: simple static landing page

Important:
The uploaded original index.html referenced /src/main.jsx, but that source file was not provided.
This ZIP therefore contains a deployable landing page, not the full original React application.

Vercel:
1. Extract this ZIP.
2. Put the folder in a GitHub repository.
3. In Vercel, select Add New -> Project and import that repository.
4. For this static page, no build command is needed; set the output directory to the project root if prompted.
